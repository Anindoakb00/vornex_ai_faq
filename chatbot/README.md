# Vornex AI Chatbot Demo

Live chatbot trained on Vornex AI's real FAQ content.

## Deploy to Vercel (FREE — 3 steps)

### Step 1 — Push to GitHub
1. Go to github.com → New repository → name it `vornex-chatbot` → Create
2. Upload both files: `index.html` and `vercel.json`
3. Commit

### Step 2 — Deploy on Vercel
1. Go to vercel.com → Sign up free with GitHub
2. Click "Add New Project"
3. Import your `vornex-chatbot` repo
4. Click Deploy — done in 30 seconds

### Step 3 — Add Groq API Key to URL
Your live URL will be:
https://vornex-chatbot.vercel.app

To pre-load the API key so April doesn't need to enter it, add it as a URL param:
https://vornex-chatbot.vercel.app?key=YOUR_GROQ_KEY

That's what you send April. She clicks, chatbot loads instantly, no setup needed.

## Get a free Groq API key
console.groq.com → Sign up → API Keys → Create → Copy
